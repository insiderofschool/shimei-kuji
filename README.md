# かたよらない指名くじ

授業で生徒をランダムに指名するアプリです。同じ生徒ばかり当たらないようにします。

## 使い方

1. ブラウザで **https://insiderofschool.github.io/shimei-kuji/** を開く（iPad の Safari、PC の Chrome / Edge どちらでも可）。PC では `index.html` をダブルクリックして開いてもよい。
2. 「クラスを追加」を押し、クラス名を入れて「名前を変更」、名簿を1行1人で貼り付けて「名簿を保存」する。
3. 「指名する」ボタンかスペースキーで抽選する。

- **一巡モード**: 全員が1回ずつ当たるまで、同じ生徒は当たりません。
- **回数バランスモード**: 当たった回数が少ない生徒ほど当たりやすくなります（全員が当たるまで待つ縛りはありません）。
- **同じ確率モード**: 直近5回に当たった人を除いて、全員が同じ確率で当たります。一度当たると次の5回は当たりません。
- 名前を押すと欠席（対象外）になります。
- 「今の指名を取り消す」で直前の指名をなかったことにできます。

### iPad のホーム画面に追加する

Safari で上の URL を開き、共有ボタン（□に↑）→「ホーム画面に追加」を押すと、アプリのように1タップで開けます。
名簿と記録はその iPad の Safari の中に保存されるので、ホーム画面から開いても Safari から開いても同じデータが使えます。

### 当たる回数を少なめにする（配慮が必要な生徒）

「名簿を編集」の下にある「当たる回数を少なめにする生徒」で名前を押すと、その生徒はほかの生徒のおよそ半分の回数になります。
この設定は名簿の一覧には表示されないので、画面を映したままでも分かりません。

### 記録

指名するたびに日時が記録されます。「記録」を押すと、縦に生徒・横に日付で回数が入った表（右に累計）と、日付ごとに誰が当たったかの一覧が見られます。
「CSV で保存」を押すと Excel でそのまま開けるファイルになります（iPad では「ファイル」アプリに保存されます）。「コピー」は Excel のセルに貼り付けるときに使います。
日時つきの全記録（1回の指名が1行）も同じように保存・コピーできます。

## データについて

名簿と記録は、開いたブラウザの中（localStorage）だけに保存されます。別の端末には引き継がれません。
移すときは「バックアップ」でコピーし、移し先で貼り付けて読み込みます。

GitHub Pages の URL で開いても、公開ページ側に送られるのはアプリ本体（`index.html`）の読み込みだけです。
生徒の名前や指名の記録は GitHub にもほかのサーバーにも送られず、その端末のブラウザの中にだけ残ります。
リポジトリ（https://github.com/insiderofschool/shimei-kuji）に入っているのはアプリのコードだけで、生徒名は含まれていません。
