# かたよらない指名くじ

授業で生徒をランダムに指名するアプリです。同じ生徒ばかり当たらないようにします。

## 使い方

1. `index.html` をブラウザで開く。
2. 「クラスを追加」を押し、クラス名を入れて「名前を変更」、名簿を1行1人で貼り付けて「名簿を保存」する。
3. 「指名する」ボタンかスペースキーで抽選する。

- **一巡モード**: 全員が1回ずつ当たるまで、同じ生徒は当たりません。
- **回数バランスモード**: 当たった回数が少ない生徒ほど当たりやすくなります。
- 名前を押すと欠席（対象外）になります。
- 「今の指名を取り消す」で直前の指名をなかったことにできます。

### 当たる回数を少なめにする（配慮が必要な生徒）

「名簿を編集」の下にある「当たる回数を少なめにする生徒」で名前を押すと、その生徒はほかの生徒のおよそ半分の回数になります。
この設定は名簿の一覧には表示されないので、画面を映したままでも分かりません。

### 記録

指名するたびに日時が記録されます。「記録」を押すと、生徒ごとの累計・今日の回数・最後に当たった日時の表と、日付ごとの指名の一覧が見られます。
「生徒ごとの表をコピー」「日時つきの全記録をコピー」で Excel に貼り付けられる形でコピーできます。

## データについて

名簿と記録は、開いたブラウザの中だけに保存されます。別の端末には引き継がれません。
移すときは「バックアップ」でコピーし、移し先で貼り付けて読み込みます。

## Claude Code で続きを作る

このフォルダで Claude Code を起動すると、`CLAUDE.md` の仕様と約束事が読み込まれます。
